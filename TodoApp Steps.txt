================================ Start ================================
Create and open :
1. run in cmd: npx @react-native-community/cli@latest init todoapp
2. open this 'todoapp' folder in VS Code

Run :
3. Connect physically Android Device with debugging mode
4. run in VS Code terminal to see device: adb devices
Res like:	List of devices attached
		    10BD4319PR0006J device
5. run in VS Code terminal: npm start
6. run in VS Code terminal: npx react-native run-android

================================ Edit App ================================

Write Code inside App.jsx / App.tsx

Set App Name : 
goto : android/app/src/main/res/values/strings.xml
add : <string name="app_name">YourAppName</string>
also change app.json
{
  "name": "todoapp",
  "displayName": "ToDo App"
}
do not change name, change displayName


Change icon : 
goto (create icon): https://icon.kitchen/


Installation:
npm install react-native-fs

================================ if need ================================
reset if need: npx react-native start --reset-cache

Clean your build if need: 
cd android
./gradlew clean
cd ..

================================ Final Steps ================================
Set gradle.properties:

goto : android/gradle.properties

MYAPP_UPLOAD_STORE_FILE=appKeystore
MYAPP_UPLOAD_KEY_ALIAS=key1
MYAPP_UPLOAD_STORE_PASSWORD=123456
MYAPP_UPLOAD_KEY_PASSWORD=123456

Set build.gradle:

goto : android/app/build.gradle

signingConfigs {
    release {
        if (project.hasProperty('MYAPP_UPLOAD_STORE_FILE')) {
            storeFile file(MYAPP_UPLOAD_STORE_FILE)
            storePassword MYAPP_UPLOAD_STORE_PASSWORD
            keyAlias MYAPP_UPLOAD_KEY_ALIAS
            keyPassword MYAPP_UPLOAD_KEY_PASSWORD
        }
    }
}
================================ Convert to APK File ================================
Using Android studio:

open 'android' folder in android studio,
goto build option
click on : generate signed app bundle or APK
select : APK
create new (if not already created)
add : E:\AndroidDev\todoapp\android\app
Set File Name : appKeystore
Password : 123456
Alias: key1
Name: Soumojit Shome, other cc
click on next
select : release
click on create

After the build completes, your APK will be here:
goto : E:\AndroidDev\todoapp\android\app\release 
and APK is done by name 'app-release.apk'

-------------------------------------------------------------------
Using Terminal:

keytool -genkeypair -v -keystore appKeystore -alias my-key-alias -keyalg RSA -keysize 2048 -validity 10000

or,

keytool -genkeypair -v -keystore android/app/appKeystore -alias my-key-alias -keyalg RSA -keysize 2048 -validity 10000


Run Build with Clean Cache:
cd android
.\gradlew.bat clean
.\gradlew.bat assembleRelease


After the build completes, your APK will be here:
android/app/build/outputs/apk/release/app-release.apk


================================ APK File Done ================================

Send this file in android device and install and use
